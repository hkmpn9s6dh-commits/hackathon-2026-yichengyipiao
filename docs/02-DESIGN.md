# 设计说明 · 《一城一票》

## 一句话

**球票与邮票是同一件东西**：都是打孔边、编号、日期、副券的一小张纸。
前者让你进场，后者让你寄出——所以十三座城市，做十三张票。

## 为什么是"票"

苏超是十三座城市轮流做主场。一场比赛，对一座城来说就是**一张票**：几号、哪座城、什么座位、谁来了。
而邮票是同一张纸的另一种命运：它被撕下来、贴上去、盖一个戳，替这座城出门。

一个"票"字，把**到场**和**寄出**两件事扣在一起，也正是这届比赛说的"城市荣耀、绿茵争锋"能落到手上的那一半。

## 系统：一票三读

| 读法 | 物件 | 作品 |
|---|---|---|
| 收藏 | 邮票（13 枚小版张） | `01-sheet` |
| 到场 | 球票（主券＋副券） | `02-poster` 主票 |
| 通行 | 护照（十三城邮戳＋十三轮记录） | `03-passport` |
| 交换 | 卡牌（63×88 标准扑克尺寸） | `04-cards` |

四件共用同一个骨架：**上图下文 + 打孔边 + 朱印 + 编号／13**。

## 十三只：同一只江豚，各戴各的冠

官方"十三太保"是同一只江豚换头饰与装饰。本作沿用这个逻辑，并把它推成一条**可生产的规则**：

- 人偶统一为**影青单色釉**（宋·青白瓷的釉色），十三只同一窑口、同一光位、同一机位。
- 城市身份只由**冠**来区分：鸭（盐水鸭）／桃（阳山水蜜桃）／虎（沛县封侯虎）／龙（龙城）／蟹（阳澄湖）／狼（狼山）／猴（花果山）／浪（运河）／鹿（麋鹿）／鹅（盐水鹅）／醋（香醋坛）／凤（凤凰城）／霸（西楚盔）。
- 颜色不上人偶，只上纸：**口号用城市色、画面底纹用城市色 13% 淡染、印章一律朱砂红**。

> 这条决定是被判据逼出来的：第一批 13 张生成图里，头饰颜色几乎全被原图的灰白带跑（苏州的蟹成了蓝的）。
> 与其 13 张各自偏色，不如统一成"同釉不同冠"——反而更像一套真实的手办。

## 颜色

纸 `#F4EFE4`／墨 `#1A1917`／朱 `#A6322A`／深绿 `#12211D`／金 `#A8823C`。
十三色只作 13% 淡染与口号色；口号色在生成时按 WCAG 对比度自动压暗到 ≥4.5:1（见 `src/design.py: ink_of`）。

## 落地

- 邮票可按小版张直接印（含过桥与声明，符合集邮品惯例）。
- 球票可按主券／副券撕线生产，编号即流水号。
- 护照可做成 32 开骑马钉小册，十三页各一枚邮戳位。
- 卡牌可按扑克尺寸开模，与盲盒同渠道销售。
- 十三枚朱印可单独做成印章套装（最轻量的周边，成本最低）。

## 已知弱项

1. 人偶是 AI 生成的"影青瓷"质感，放大到 A2 主票（150 mm 宽）时约 250 dpi，低于 300 dpi；邮票尺寸（60 mm）下充足。
2. 冠的形制是"像"，不是官方设定稿：拿到官方 IP 素材库后应替换为授权图（`assets/art/city/*.png` 一处替换，`build.py` 重跑即可）。
3. "球场概念效果图"这一项本轮主动删去，见 `SPEC.md` §五。
